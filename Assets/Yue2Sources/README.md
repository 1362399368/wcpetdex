# 玥2：30 fps 分动作动画包

## 素材与输出

本目录的 `build_yue2.py` 是当前玥的可编辑动画骨架装配脚本，复用 `../YueSources/` 的人物图层。新转向关键姿态由内置 imagegen 生成，保存在 `turn-keys-smooth.png`；按五列两行读取，共十个正面到左侧的视角。生成不会改写旧 `Resources/DefaultPet/`。

输出为 `Resources/Yue2Pet/pet.json` 与 `row-00.png` 到 `row-28.png` 共 29 条动作图。v5 每条 3840×208，单帧 192×208，20 列；转向兼容行 9 / 10 各 16 个有效帧，其余各 20 帧。合计 **572 个有效帧、30 fps**，相较旧版 **286 帧、15 fps** 增加一倍。动作语义、在线玩手机、慢眨眼触发规则保持不变。

需要支持 v5 分动作加载的插件版本 1.0.5 或更新。旧 1.0.4 导入器只支持最多十列，不能导入本包。`spritesheetPath` 指向 `row-00.png` 作为预览别名，真正的 29 条文件列表在 `rowAtlasPaths`。

## 补帧方法与实际范围

- 行走使用二十个连续时间相位求解双腿关节，四段骨长固定，两腿错开十帧。小腿相对大腿存在回收相位差，使二十个腿姿都不同，不是把旧十帧各重复一次。
- 旧关键帧的大腿 / 小腿角度突变由连续曲线替代；每帧关节角变化小于 19 度，循环接缝也按相同曲线处理。头部一直复用同一层，只有最多 1.5 像素轻微起伏。
- 刚性平移和旋转使用四倍超采样，减少整像素移动造成的跳动，所有缩放均保持横纵同比例。
- 待机 / 玩手机仍约 5.2 / 5.6 秒眨眼一次；一次完整闭眼为四个 30 fps 帧，即约 0.133 秒，与旧版两帧 / 15 fps 相同。增加帧率没有加快眨眼频率。
- 挥手、抚摸、想念、跳跃、抱膝、落地和摇动等使用原画关键姿态加连续的轻微位移 / 倾斜 / 缓入缓出，不通过整张脸透明叠化制造双影。静止停顿允许复用画面，并未声称 572 帧全是不同姿势。
- 从边缘出来 / 收入边缘使用十个实际生成的连续视角，分布到二十个采样时刻，并配合轻微连续动作。十个视角不是二十个独立新视角；普通转身兼容行仍保留原背面等关键姿态。
- 新前向姿态和转身图按鞋底中心对齐，避免长发改变人物包围框中心而导致转身时整个人横向漂移。左右奔跑、左右探头为逐帧精确镜像。

## 内存与体积

一条动作解码 RGBA 像素约 3.05 MiB，完整二十列大图等价像素约 88.36 MiB。实际插件按动作条加载，无须把整套图集同时解码；具体运行内存与加载策略以插件代码及运行测试为准。全部 PNG 与 JSON 约 17 MiB，导出 ZIP 保持 32 MiB 导入上限以内。

## 复现与检查

```
python3 Assets/Yue2Sources/build_yue2.py
python3 Tests/check-yue2-animation.py
```

依赖 Pillow，输入图像均保留在项目中。`Review/gait-joints.json` 保存二十帧的关节、缩放和位移记录；`Review/walking.gif`、`expressions.gif`、`interactions.gif`、`edge.gif` 与 `all-rows.jpg` 用于复核。当前测试报告在 `Tests/yue2-animation-report.json`，检查直接读取最终 PNG 文件，包含独立腿姿、骨长、循环角度步长、连通、透明边距、镜像、头部稳定、慢眨眼、转身根点和探头接缝。本地素材检查不等于微信真机验收。
